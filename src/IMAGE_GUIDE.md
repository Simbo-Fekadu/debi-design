# DEEBII Design - Image Integration Guide

This guide will help you organize and add images from your GitHub repo to the website.

## Image Categories Needed

### WOMEN Collection (3-5 images)
- Traditional Habesha dresses
- Modern Ethiopian women's wear
- Formal/casual designs
- Example names: `women-1.jpg`, `women-2.jpg`, etc.

### MEN Collection (3-5 images)
- Traditional men's attire
- Modern Ethiopian menswear
- Formal/casual designs
- Example names: `men-1.jpg`, `men-2.jpg`, etc.

### COUPLES Collection (2-3 images)
- Matching sets
- Wedding attire
- Special occasion outfits
- Example names: `couples-1.jpg`, `couples-2.jpg`, etc.

### KIDS Collection (2-3 images)
- Children's traditional clothing
- Festival wear
- Various age groups
- Example names: `kids-1.jpg`, `kids-2.jpg`, etc.

### HERO/BANNER Images (1-2 images)
- High-quality hero banner image
- Should showcase brand aesthetic
- Example name: `hero-banner.jpg`

### ABOUT/HERITAGE Section (1-2 images)
- Behind-the-scenes
- Craftsmanship details
- Cultural elements
- Example name: `heritage.jpg`

## How to Add Images

### Step 1: Upload Images
Upload your images in this chat, and I'll integrate them using:
```tsx
import imageName from 'figma:asset/[hash].png';
```

### Step 2: Or Provide Direct URLs
Share the direct image URLs from your deployed site:
```
https://deebii-design.vercel.app/images/women-1.jpg
```
